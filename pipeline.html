📂1 — File IngestionACCUMULATIVE
Drag & Drop / Browse→ isDICOM(f)→ FileReader.readAsArrayBuffer+ loadRasterFile(PNG/JPEG/TIFF)
DICOM (.dcm, extensionless) PNG / JPEG TIFF (multi-page via UTIF.js) Multi-drop accumulation
De-duplication by seriesUID + instNum + filename. Each drop adds to existing slices[]. "Clear all" resets explicitly. Max 1000 files/drop.
🔬2 — DICOM / Raster ParsingPER FILE

DICOM parser (parseDICOM)

Tag walk — groups 0008/0010/0018/0020/0028 PixelData offset detection rescaleSlope/Intercept (rs/ri) seriesUID → fallback: modality+seriesNum instNum, bitsAlloc, pixelRep, isCT

Raster parser (makeRasterSlice)

PNG/JPEG → <img> via URL.createObjectURL TIFF → UTIF.decode → UTIF.decodeImage → RGBA8 Multi-page TIFF → one slice per IFD modality=IMG, seriesUID=raster-filename
All slices stored in global slices[] and sorted by seriesNum → instNum.
🔒3 — Anonymisation (HIPAA §164.514)IN-MEMORY
anonPID → SHA-256(patientName) → "Patient-3A7F" anonDOB → year only anonDate → year + month
Raw pixel data and original tags stay in memory for rendering. Only anonymised strings enter the AI context and audit log. Multi-patient: all unique anonPIDs listed with ⚠ warning in AI prompt.
📋4 — Series Grouping & ViewerVIEWER
buildSeriesTable()→ seriesGroups{uid→slices[]}→ Chip panel per series→ ☑ checkbox = include in AI
Window/Level: CT uses DICOM WC/WW tags. MRI uses percentile windowing (p2–p98, background-excluded histogram). Mouse drag = W/L adjust. Multi-series interleaving for AI analysis.
🖼5 — AI Image Preprocessing PipelineAI TILES

Step A — Per-slice optimal windowing

computeSliceHistogram(slice) Exclude background (<5% of mean) percentilesFromVals(p0.5, p99.5) → per-slice wc/ww (not global viewer W/L) CT: keeps viewer W/L (user-set)

Step B — CLAHE enhancement

8×8 tile grid on each cell Clip limit 3.0 (prevents noise amp) Bilinear interpolation (no block artifacts) Applied AFTER windowing, AI-pipeline only Viewer display unchanged

Step C — Two-pass tile construction

Pass 1 — Survey: 4×4 grid · 192px/cell · 768px tile→ up to 640 slices · ≤38 tiles→ MRI: lossless PNG CT: JPEG 88%
Pass 2 — Full-res crops: 4 key slices (current + middle ⅓)→ Native res ≤512px · lossless PNG · CLAHE→ MRI only
Series label (cyan, bottom-left of cell) in multi-series mode. Yellow slice# top-left. Series interleaved round-robin so DWI/ADC/FLAIR cells are adjacent.
